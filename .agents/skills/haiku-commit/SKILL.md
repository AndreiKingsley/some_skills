# Хайку-коммит

1. Посмотри `git diff --staged` (или `git diff`, если staged пусто).
2. Сочини хайку из трёх строк (5-7-5 слогов), описывающее изменения.
3. Выведи его пользователю. Сам не коммить — пусть человек насладится поэзией.

Пример:

```
Тихий null упал
Проверку я добавил
Прод спит спокойно
```
